#AI Course Generator

An AI-powered web application built with Next.js that helps users generate personalized courses and structured learning paths using Artificial Intelligence.

Features
Generate courses using AI.
Create personalized learning paths.
Generate structured course chapters and topics.
User-friendly and responsive interface.
Simplifies the course creation process.
Technologies Used
Next.js
React.js
JavaScript
Artificial Intelligence (AI)
Tailwind CSS
Getting Started

First, install the dependencies:

bash
npm install


Run the development server:

bash
npm run dev


Open http://localhost:3000 with your browser to see the application.
